자동 로그인이 무작위로 풀림 JOYHILL · 프런트엔드 인증

증상로그인 유지가 켜져 있는데도 사용자가 가끔 로그아웃됨
원인토큰 갱신 코드가 화면마다 약 20곳에 복사돼 있었고, 갱신 때마다 새 리프레시 토큰이 발급되는데 인증 상태 동기화 로직이 오래된 토큰으로 새 토큰을 덮어씀
해결토큰 갱신을 session.js 한 모듈로 통합해 갱신 경로를 하나로 만듦 (v0.2.1)

사진 업로드 실패 — 413, 500, 502가 차례로 JOYHILL · 인프라

증상업로드 기능 배포 후 사진이 올라가지 않음. 고칠 때마다 다른 에러 코드가 나옴
원인413은 nginx client_max_body_size 기본값(1MB), 500은 EC2에 S3 접근 IAM Role이 연결되지 않음, 502는 재시작 직후 앱 기동 지연
해결워크플로로 업로드 한도 32MB 설정 → IAM Role 연결 → 기동 대기. 원인 구분법을 백엔드 문서에 남김

인증이 만료돼도 로그아웃되지 않고 에러 화면에 갇힘 QTPot · Spring Security

증상세션이 만료된 사용자가 자동 로그아웃되지 않고 계속 에러 상태
원인formLogin을 쓰지 않아 인증 실패 진입점이 Spring Security 기본값(403)으로 떨어짐. 프런트엔드는 401에서만 자동 로그아웃하도록 되어 있었음. 또 sendError()를 쓰면 /error로 forward되며 JWT 필터가 다시 돌지 않아 403이 401로 덮임
해결authenticationEntryPoint(401)와 accessDeniedHandler(403)를 분리 등록하고, setStatus() + JSON 본문으로 직접 응답

백업이 새벽이 아니라 낮에 돎 JOYHILL · 스케줄러

원인서버 시간대가 UTC이고 @Scheduled에 zone이 없었음. 화면의 백업 시각도 9시간 어긋나 보임
해결zone = "Asia/Seoul" 지정, 시각은 +09:00 오프셋을 붙여 직렬화

게시글 삭제 시 500 QTPot · JPA

원인인증 글에 달린 댓글·좋아요에 cascade 매핑이 없어 FK 위반
해결삭제 전에 자식 데이터를 명시적으로 지우도록 서비스 로직 수정

앱 재실행 후 푸시가 끊김 QTPot · PWA

원인FCM 서비스 워커와 PWA 서비스 워커가 같은 스코프를 놓고 서로 교체
해결FCM은 SDK 기본 전용 스코프에 등록되게 바꿔 두 워커를 분리

출석이 두 번 집계됨 JOYHILL · 데이터

원인구글시트에서 옮겨 온 과거 출석과 앱에서 새로 쌓인 출석이 같은 기간에 함께 합산됨
해결집계 로직을 추적해 중복 합산을 바로잡음
