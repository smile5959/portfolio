BEFORE
회원이 단체 대화방에 묵상 사진을 올리면, 관리자가 대화방을 넘기며 누가 올렸는지 직접 세어 확인했습니다. 인원이 늘수록 놓치는 사람이 생기고, 기간별로 다시 보기도 어려웠습니다.
→
AFTER
회원은 앱에서 사진으로 인증하고, 기록은 자동으로 쌓입니다. 관리자는 한 화면에서 사람별·날짜별 인증 현황을 봅니다. 인증을 잊지 않도록 정해진 시각에 푸시 알림을 보냅니다.
해결한 문제
관리자가 매번 손으로 하던 인증 집계. 확인 누락과 기간별 조회의 어려움.
본인 구현 범위
기획, 화면, 프론트엔드, 백엔드, 배포·운영 전부. 사진 자동 최적화, 관리자 현황 화면, 푸시 알림, 성장 뱃지와 월간 랭킹.
결과
956회 누적 인증

운영하며 고친 것 · 세션이 만료된 사용자가 빈 화면에 갇히는 문제가 있었습니다. 서버가 인증 실패를 모두 403으로 돌려줘서, 401일 때 로그인 화면으로 보내는 처리가 한 번도 동작하지 않았던 것이 원인이었습니다. 두 응답을 분리해 고쳤고, 막혀 있던 사용자도 따로 안내 없이 다음 요청에서 로그인 화면으로 넘어갔습니다.

여기서 배운 것 · AI에게 파일 수정이나 외부 앱 작업을 맡길수록 "무엇을 사람이 확인하고 넘어갈지"가 중요했습니다. 사내 자동화에서도 되돌리기 어려운 작업에는 확인 단계를 두겠습니다.

일하는 방식AI로 만들되, 결과는 그대로 받지 않습니다

AI에 맡길 일과 제가 직접 정하고 검증할 일을 나눕니다. 코드는 AI 코딩 도구로 빠르게 만들고, 아래 세 가지는 제가 책임집니다.

먼저 듣고 정합니다

무엇이 반복되고 누가 불편한지부터 확인합니다. 권한 구조나 데이터 흐름처럼 되돌리기 어려운 결정은 직접 정하고 이유를 남깁니다.

돌려 보고 받아들입니다

만든 것은 실제 데이터와 운영 환경에서 확인합니다. 출석이 두 번 집계돼 출석률이 100%를 넘었을 때도 데이터 흐름을 따라가 원인을 찾아 고쳤습니다.

쓰이게 만듭니다

배포로 끝내지 않습니다. 사용 가이드를 만들고, 들어오는 요청과 오류를 반영하며, 실패가 조용히 묻히지 않게 기록을 남깁니다.

입사 후계약 3개월 동안 보여 드릴 것

넷폼은 연구개발부터 시공, 운영, 사후관리까지를 250여 곳의 파트너사와 함께 하고 있습니다. 이런 환경에서는 부서와 담당자 간 정보 전달, 자료 취합, 진행 현황 확인을 일관성 있게 관리하는 것이 중요하다고 생각합니다. 무엇을 먼저 자동화할지는 현업의 이야기를 듣고 기준을 세워 정하겠습니다.

파악 · 우선순위

인터뷰와 업무 흐름 분석으로 반복 작업을 찾고, 빈도·소요 시간·오류 가능성·난이도로 순서를 정합니다.

작게 적용

효과가 빨리 보이는 자동화 1~2개를 실제 업무에 붙입니다. 현업이 직접 고칠 흐름에는 n8n·Make를 익혀 씁니다.

검증 · 정착

처리 시간·오류·피드백으로 효과를 확인하고, 실패 알림과 사용 가이드를 붙여 현업이 쓰고 고칠 수 있게 넘깁니다.
