1. 해결하려 한 문제동기화 오류가 반복되던 시트 기반 출석 관리

교회 청년부(리더·마을장·교역자 등 다섯 가지 역할)가 출석과 조직 정보를 관리하던 방식에서 출발했습니다.

BEFORE
출석을 앱시트와 구글시트 연동 스크립트로 관리했습니다. 스크립트가 시트와 앱 사이 데이터를 잘못 저장하는 동기화 오류가 반복됐고, 출석·공지·기도제목·새가족 관리가 여러 곳에 흩어져 있었습니다. 운영진은 구글시트로 데이터를 보는 데 익숙했습니다.
→
AFTER
회원·조직·출석 기록을 자체 DB로 옮기고 관리를 한 서비스에 모았습니다. 구글시트는 없애지 않고 매일 자동으로 채워지는 사본으로 남겨, 운영진이 쓰던 방식을 바꾸지 않아도 되게 했습니다. 역할마다 볼 수 있는 범위를 나눴습니다.
Figma교인 전체로 넓히는 새 앱 와이어프레임 서비스는 교인 개인정보가 있어 로그인 전용이고 저장소는 비공개입니다. 코드는 면접에서 화면을 공유해 보여 드릴 수 있습니다.

2. AI와 제가 각각 한 일코드는 대부분 AI가, 판단과 확인은 제가

Claude Code로 만들었습니다. 저는 AI 없이 이 코드를 처음부터 짤 수 있는 수준은 아닙니다. 대신 무엇을 만들지, 제대로 만들어졌는지, 틀렸다면 왜인지를 맡았습니다.

단계AI가 한 일제가 한 일
문제 정의—운영진이 시트를 어떻게 쓰는지 보고, 무엇을 서비스로 옮기고 무엇을 시트에 남길지 정했습니다.
설계제가 정한 규칙대로 테이블과 API 초안 작성역할별 접근 범위, 데이터를 옮기는 기준, 「AI 결과는 바로 반영하지 않고 개편안에만 넣는다」처럼 되돌리기 어려운 결정은 직접 정하고 이유를 문서에 남겼습니다.
화면Figma AI로 화면 초안, 코드로 화면 구현실제 폰에서 써 보고 어색한 곳을 다시 지시했습니다. 시안을 두세 개 받아 비교한 뒤 골랐습니다.
구현코드 대부분 작성, 테스트 코드 작성작업을 작게 나눠 맡기고, 바뀐 코드를 읽어 의도와 다르면 되돌렸습니다. 기능마다 PR로 나눠 머지했습니다.
검증같은 유형의 오류를 전체 코드에서 찾아 목록화실제 데이터와 운영 서버에서 결과를 확인했습니다(출석률, 백업 시각 등). 숫자가 이상하면 데이터 흐름을 따라가 원인을 판단했습니다.
운영 · 문서저장소별 작업 기록(CLAUDE.md) 갱신역할별 사용 가이드 10쪽을 직접 만들어 공유했습니다. 제보를 받아 무엇부터 고칠지 정하고 배포했습니다.
AI가 맥락을 잃지 않게 · 저장소마다 진행 상황, 지켜야 할 규칙, 이미 겪은 함정을 문서(CLAUDE.md)로 남겼습니다. 예를 들어 「서버 시간대가 UTC이니 새 스케줄에는 반드시 시간대를 적을 것」을 적어 두어, AI가 같은 실수를 반복하지 않게 했습니다.

3. AI가 만든 코드에서 오류의 원인을 찾아 고친 일그대로 받지 않고, 원인부터 확인했습니다

AI가 쓴 코드는 대부분 잘 돌았지만, 실제로 쓰다 보면 겉으로는 다른 문제처럼 보이는 오류가 나왔습니다.

자동 로그인이 가끔 혼자 풀림

원인AI가 화면을 만들 때마다 토큰 갱신 코드를 복사해 넣어, 약 20곳에 흩어진 코드가 서로의 저장 값을 덮어썼습니다.
수정한 모듈로 모으고, 동시에 한 번만 갱신하며, 인증 실패(401·403)일 때만 로그아웃하게 했습니다.

출석률이 100%를 넘음

원인데이터를 옮길 때 「기존 집계값은 앱 이전 기록」이라는 추측대로 1~4월 주차 기록을 다시 넣었습니다. 실제로는 집계값이 이미 1~4월을 담고 있어 두 번 집계됐습니다.
수정원본 시트와 대조해 확인하고 「주차별 기록은 5월부터만」으로 기준을 정해 문서에 남겼습니다.

설교노트 자동 번호 목록이 엉킴

과정AI의 첫 수정은 자동 번호 기능을 아예 없애는 것이어서 반려했습니다. 두 번째는 일부 경우만 막아 다시 재현됐습니다.
수정세 번째에 목록을 만드는 방식 자체를 바꿔 근본적으로 고쳤습니다. 기능을 없애는 것은 수정이 아니라는 기준을 남겼습니다.

새벽 백업이 낮 12시에 돎

원인서버 점검 중 발견했습니다. 서버 시간대가 UTC인데 스케줄에 시간대가 없어 9시간 어긋났습니다.
수정Asia/Seoul을 명시하고, 마지막 백업 시각은 시트 쓰기에 성공했을 때만 기록해 실패가 성공처럼 보이지 않게 했습니다.
